# Arnob Banik — Portfolio

Personal portfolio for Arnob Banik, an AI and full-stack software developer based in Windsor, Ontario.

## Featured work

- Color-Aware Composed Image Retrieval — MSc research using CLIP, RGB-box constraints, voxelized partitions and HNSW search.
- Job Application Intelligence Dashboard — Next.js, TypeScript, Supabase/PostgreSQL, Gemini/OpenAI, Gmail and Vercel.
- Flowdesk — multi-user household CRM built with Next.js, TypeScript, Prisma, Neon, Auth.js, PWA tooling and Capacitor.

## Stack

- React 18 and Vite 5
- Tailwind CSS 3
- Accessible single-page navigation
- Responsive case-study layouts
- SEO, Open Graph and structured profile metadata

## Local development

Install dependencies and run the development server:

    npm install
    npm run dev

Create a production build:

    npm run build

## Deployment

The site is deployed on Vercel at https://abanik.vercel.app/.
